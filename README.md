# MACHINE-LEARNING
Curso de Maestria Ciclo I

Instalar desde la terminal lo siguiente:
•	pip install joblib
•	pip install streamlit
•	streamlit run app1.py
•	pip show streamlit
•	pip install scikit-learn==1.6.1
Es posible que te pida instalar mas librerías sugeridad, solo continuar e instalar

Para ejecutar el app.py, escribir en la terminal:
•	python -m streamlit run app1.py
